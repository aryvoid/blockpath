# Blockpath

Minecraft coordinate distance calculator: paste two positions, get remaining blocks, heading, travel time, and Nether pairing.

## Open it

**GitHub:** https://github.com/aryvoid/blockpath

To run on your machine:

```bash
npm install
npm run dev
```

## Features

- Paste F3 / HUD / `/tp` coordinates
- 3D + horizontal distance, chunks, deltas
- North-up compass and relative map
- Travel times (walk, horse, ice boat, elytra)
- Nether X/Z pairing
- Saved waypoints in the browser

## Stack

React 19, TanStack Start, Tailwind CSS v4.
